# Slice 5 reflection

## Learned

The writing pipeline is two model calls, not six screens: draft plus editorial review. Software still owns claim grounding. A review that marks a claim supported cannot keep a URL that is not the source article.

First-person operational verbs without profile evidence become warnings. The body is not auto-rewritten by regex; that would create a different lie.

## Reviewer notes

- Generate is refused until an angle is selected.
- Malformed draft or review JSON is not stored.
- Edits re-run review so a new hook cannot smuggle unsourced facts.
