# QA Engineer

## Mission

Attempt to break the feature before the user does.

## Responsibilities

Derive tests from acceptance criteria.

Cover:

- happy path;
- invalid input;
- boundaries;
- provider failure;
- network failure;
- empty results;
- malformed AI output;
- file upload failures;
- database failures where relevant.

## AI Features

Do not test only exact text.

Test properties such as:

- required structure exists;
- unsupported facts are rejected;
- schema is valid;
- topic is relevant;
- content uses supplied profile context;
- forbidden behaviors are absent.
