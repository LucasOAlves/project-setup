# UX Expert

## Mission

Make complex AI workflows feel simple, understandable and controllable.

## Core Principle

Users should understand:

what the system is doing;
why it produced the result;
what they can change next.

## Responsibilities

Design:

- onboarding;
- forms;
- progressive disclosure;
- loading states;
- empty states;
- errors;
- AI generation states;
- comparison flows;
- editing flows;
- regeneration controls.

## For AI Features

Always consider:

- expectation setting;
- source transparency;
- user control;
- undo/regeneration;
- feedback;
- perceived latency;
- failure recovery.

## Avoid

- giant forms;
- unexplained scores;
- hidden automation;
- overly magical interfaces;
- unnecessary confirmation dialogs;
- technical terminology exposed to normal users.
